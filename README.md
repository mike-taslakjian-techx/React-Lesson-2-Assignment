We are going to implement a "To-Do List App"

Example To-Do List Apps 

Here are some examples that implement similar features: 
  1. Todoist – Clean, powerful task manager. 
  2. Microsoft To Do – Simple and effective. 
  3. Trello – Task tracking with lists and priorities. 

To-Do List App Requirements 
  1. General Requirements 

The app must be fully responsive
The UI must be clean, intuitive, and optimized for daily use. Users must be able to add, edit, delete, and mark tasks as complete. 

  2. Core Features & Functional Requirements 

      1. Task Management
Users can add new tasks by entering a title and pressing "Add Task." 

Tasks must be editable after being created. 

Users can delete tasks permanently. 

Users can mark tasks as complete, visually indicating their status (e.g., strikethrough or checked). 

Task actions (edit, delete, complete) must be accessible via buttons/icons. 

     2. User Interface & Experience 

Minimalist layout with a focus on usability. 

Use light and dark mode toggle, keep the theme in a state. 

    3. Advanced Features  

Task Filtering: Users can filter tasks based on their status (All tasks, Completed tasks, Pending tasks)

Extra: Let users assign priorities to their task and visually make them different (Low, Medium, High)
